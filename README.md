# HolyGPT-inh

**HolyGPT-inh** — экспериментальная русскоязычная модель для генерации текста на православную и христианскую тематику.

## Публичный выпуск

Этот репозиторий предназначен **только для готовой модели для инференса** в формате GGUF.

- Версия: `step23837`.
- Планируемый файл: `model/holygpt-inh-step23837-f16.gguf`.
- Совместимость с Ollama будет отмечена после фактической проверки.
- Модель является экспериментальной и может допускать ошибки, придумывать цитаты и неточно воспроизводить религиозные тексты.

**Исходный код обучения, конвертер, датасеты, токенизатор в исходном формате, полный training checkpoint и состояния оптимизатора не публикуются.** GGUF включает необходимые для инференса веса и данные токенизации.

### Статус

Репозиторий подготовлен. **GGUF с обученными весами пока не загружен.** Экспорт FP16 шага 23837 создан, однако текущая сборка аварийно завершается при загрузке в Ollama (`llama-server`: `abort trap`); совместимость проверяется. Не считать файл рабочим до устранения этой ошибки.

### Запуск на Mac через Ollama

После публикации и проверки GGUF создайте локально рядом с ним файл `Modelfile`:

```text
FROM ./holygpt-inh-step23837-f16.gguf
TEMPLATE "{{ .Prompt }}"
PARAMETER num_ctx 512
PARAMETER temperature 0.8
PARAMETER top_k 40
PARAMETER repeat_penalty 1.1
```

Затем выполните `ollama create holygpt-inh:step23837 -f Modelfile` и `ollama run holygpt-inh:step23837`.

## Использование

Правила распространения и использования весов определяются правообладателем отдельно. Наличие публично доступного GGUF не означает публикацию исходного кода или разрешение на обучение производных моделей.
